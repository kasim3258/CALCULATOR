# SmartCalc

A modern scientific calculator built with vanilla HTML, CSS and JavaScript.

## Features
- Arithmetic operations and percentages
- Powers, square roots and factorials
- sin, cos, tan, log, ln
- DEG/RAD angle modes
- Memory: MC, MR, M+, M-, MS
- Calculation history with localStorage
- Keyboard input
- One-click result copy
- Dark/light theme
- Responsive UI

## Run
Open `index.html` in a modern browser.

No backend or API key is required.
